# Robotics layer

Reserved for Prometheus's future physical body. Keep real-time control and hardware safety isolated from the companion-AI executive.

Planned integration points:
- ROS 2: middleware and device communication
- MoveIt 2: manipulation/motion planning
- LeRobot: learned robot skills and datasets
- MuJoCo: simulation and control experiments

High-level Prometheus intent must pass through explicit permissions and a robotics safety supervisor before reaching hardware.
