# Adaptive Prometheus interface

Double-click `START-PROMETHEUS-SSD.cmd` or `START-PROMETHEUS-INTERFACE.cmd` on the drive. The local interface opens at http://127.0.0.1:54555/. `START-PROMETHEUS-PORTABLE.cmd` still provides the command line. The interface starts without loading an AI model.

Your approved cyan/violet artwork is preserved. **Simple** uses a flat orb and modest thinking/speaking motion. **Flow** adds a liquid surface. **Immersive** adds more fluid detail and orbiting code. **Still** retains the image and text status without animation. These are visual effects, not a scientific fluid simulation.

Automatic display selection uses available RAM, CPU thread count and actual render timing. A healthy 8 GB computer can advance beyond Simple; a busy high-memory computer can reduce effects. Upgrades require 30 seconds of stable measurements per level. Downgrades respond to memory pressure and repeated slow frames, with a cooldown before upgrading. Hidden tabs and reduced-motion preferences stop animation. Manual Simple and Still settings are available. Display adaptation does not lower the separate model memory requirements.

## Working with Prometheus

- **Conversation:** task-sensitive model selection by default. Exact arithmetic can run directly. When no model fits, source excerpts are returned in clearly labeled reference mode.
- **Coding assistant:** ask for code, debugging, explanations or tests. Choose a language to guide the prompt, or leave Auto. Supported source-file searching spans many mainstream and specialized languages; selection is not a compiler installation or an accuracy guarantee.
- **Offline references:** law/government, medical, mathematics, engineering/code, OpenAI development and general archives. Results retain citations and original material remains available.
- **Exact calculation:** use numbers, parentheses, `+ - * / **`, such as `(24 * 17) / 3`.
- **Public research:** choose a publisher; sending explicitly shares the search query with that publisher.
- **Project search:** provide the existing folder containing your project. Results include file/line evidence. Dependency/build folders and hidden files are skipped. This does not execute or modify code.
- **Saved conversations:** resume one of the recent sessions. The display loads the latest 40 messages; earlier messages remain in the database.
- **Record 8 seconds:** explicitly starts the Windows microphone and local Whisper transcription. Review the transcript before sending. **Read answer aloud** uses an installed local browser voice; no online voice is chosen. Actual speech events drive the speaking pulse.
- **Helpers:** lists installed models, their configured roles and current fit estimates. Model choice is automatic for each request, including after changing tasks. One UI request/model runs at a time; this is not concurrent multi-agent work. Embedding models remain available to Ollama clients, not as chat answer generators.

Close the interface to release its SSD session lock before opening a separate portable coding session. The installed Codex/Hermes and seven additional tools have their own launchers and account requirements. The browser interface does not run arbitrary shell commands or approve agent file changes.

Use **Close Prometheus** before safe removal. It lets an active request finish, closes reference-file handles and releases the portable lock. Closing the browser alone leaves a five-minute inactivity timeout. Do not unplug until Windows confirms safe removal. No camera capture, image rendering or physical device acceptance is implied by this interface release.

The model router uses explicit roles and conservative memory estimates, not learned quality scores. Sources, generated answers and code still need the checks appropriate to your task. It cannot acquire all public knowledge, support every language perfectly or certify legal/medical advice. Existing signed recovery and memory protection remain active.

Animation lifecycle follows [requestAnimationFrame](https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame) and [page visibility](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API). Speech requires a [local browser voice](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisVoice/localService).
