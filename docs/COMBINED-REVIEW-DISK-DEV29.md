# Combined review and disk release — dev29

This candidate combines the dev28 advisory-review, battery-observation and
exclusive Windows listener work with the native physical-disk observer and
dashboard. The signed dev28 payload is the packaging baseline; the installed
dev27 revision 2 release remains the installation and rollback baseline.

Advisory findings stay bound to the exact proposed bytes and retain provenance
through approval, saved history and undo. They never confer owner authority.
The accepted browser workflow used labeled simulated model responses; the
approval, file changes, deterministic checks and persistence were real.
Real local-model response quality remains pending adequate memory headroom.

Windows disk sampling validates the configured data-volume physical identity,
uses bounded one-shot child processes, and coalesces readers through a cache.
The UI labels whole-device measurements, age and missing values. These readings
do not change scheduler admission, workload cost, approval or Surface dispatch.
Battery observations likewise describe whole-device percentage change, not
per-job energy. The Surface worker and its enrollment are unchanged.

Release qualification must verify the signed payload/archive, run the complete
packaged regression and UI suites, exercise the portable Python dependencies
and native disk helper, and pass a read-only installation/rollback preflight.
Results are saved outside the immutable package against its manifest hash.
Installation, backup and activation require a separate owner approval.
The broader planning roadmap remains unfinished.
