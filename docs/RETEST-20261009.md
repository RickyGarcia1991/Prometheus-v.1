# SSD interface retest and smart-home standby

This source synchronizes the previously installed local SSD enhancements with Git, repairs the browser fetch receiver that prevented interface connection, and adds an explicit Smart home mode backed by configured Home Assistant entities. The connector starts disabled and requires hub-bound Windows credentials and a separate browser control key. See SMART-HOME.md for pairing, supported commands, platform limits and Drop In handoff. Maps & Studio 1.0.1 is under tools/maps-studio.

Validation on Windows with Python 3.12.14 and Node 24: 621 core tests passed, two link-creation privilege tests skipped; 13 core UI tests/runners passed; 24 Studio Python tests and 13 Studio UI tests passed. Real browser checks covered connection, calculation, smart-home standby, project open/read/preview/apply/undo/syntax check, map loading/regions/date metadata, NASA images/Earthdata, image transforms/reset and directory filters. No live smart-home pairing, microphone/speaker physical test or eject/reinsert acceptance is claimed.

The Python tests use isolated directories and loopback stubs. Windows PowerShell tests require the Windows PowerShell module path rather than an inherited PowerShell 7 module path.

Run `pytest -q`, `node --test tests/ui/*.cjs`, `python tools/maps-studio/test_studio_backend.py`, and `node --test tools/maps-studio/test_studio_ui.cjs`. Stubbed device tests do not certify physical hardware or provider accounts.
