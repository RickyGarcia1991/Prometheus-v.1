# Public reach — dev10

Open Owner workspace → Public reach · online. Select Web page text, RSS/Atom feed, GitHub repository, GitHub latest releases, Find GitHub repositories, YouTube title/channel, or YouTube English transcript. Enter the URL (or owner/repository/search text) and Send. Results are saved with timestamps, source URLs and response hashes. No model is required.

This is a scoped adaptation of https://github.com/Panniantong/Agent-Reach channel architecture, not installation of its whole package. Agent-Reach primarily installs/checks/routs underlying tools. Its v1.5.0 tagged installer has broad system and browser-cookie side effects; no installer, doctor, global skill or account configuration is executed. No Agent-Reach source was copied.

Public web/feed/GitHub/metadata use the existing DNS-pinned HTTPS transport. Public English captions use the pinned yt-dlp 2026.8.19 Python wheel (SHA256 1d57897e94c6665a0a6f9bc54b34e584284e32c034ffab3a7df25d8f7b24eedf), distributed under the included Unlicense. The isolated -I -S child disables plugin discovery, user/site configuration, account cookies, proxy inheritance, JavaScript runtimes and remote components. Only the reviewed urllib handler is used; DNS and numeric connections are checked against public YouTube hosts/global IPs. Redirects, compressed responses and large declared bodies are rejected before yt-dlp decompression; body reads, output, request count and lifetime are bounded. No media downloader executes. Transcripts are source evidence, and automatic captions can be inaccurate.

Limits: no general search engine, account-backed social connections, JavaScript page rendering, paid cloud processing, video/audio downloads or OCR. English captions may be absent or service-limited. Pages/feed encodings other than UTF-8 are unsupported. Source text may be shortened with truncation metadata. Core reach/read requires network approval; normal conversation does not browse automatically. Owner passkeys and local history remain in place.

Evidence: 204 affected Python tests passed; app lifecycle/source UI tests and the new public-mode submission check passed. Seven real public read operations passed on Dell. The isolated transcript worker also passed using the existing portable Python (427 caption segments, 59,007 bytes, 3 requests on the tested public TED video). These are bounded checks, not a guarantee all sites/videos work.
