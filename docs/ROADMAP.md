# Roadmap

## Milestone 1 — Foundation
Package layout, contracts, configuration, tests, CI/security baseline.

## Milestone 2 — Local cognition
Evaluate llama.cpp-compatible local models and add a streaming model adapter.

## Milestone 3 — Durable memory
Define memory types, retention, provenance, deletion and retrieval. Evaluate Qdrant versus simpler local storage.

## Milestone 4 — Voice and perception
Add local STT, TTS and vision behind stable interfaces.

## Milestone 5 — Tools and controlled learning
Permission model, audit log, sandboxed tools and evaluation harness.

## Milestone 6 — Embodiment research
Simulation first; ROS 2 / MoveIt 2 / LeRobot adapters later. No direct LLM-to-actuator path.
