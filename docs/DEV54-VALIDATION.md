# Dev54 revision 2: bounded evidence follow-up checks

This release allows an owner to request a fresh syntax or fixed-profile lint check from an active interpretation of conflicting evidence. The new proposal binds the exact interpretation, observed evidence, selected files, destination and worker. Approval creates a separate result and provenance record. Rejection, cancellation, waiting, stale inputs and uncertain outcomes remain explicit.

Original observations, failed checks, conflicts and interpretation history remain unchanged. Follow-up results do not select a conflict winner or grant execution authority to historical records. Dedicated waiting storage keeps this work separate from earlier releases; rollback to dev53 preserves the new records without resuming their queue.
